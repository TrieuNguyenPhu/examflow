# Contributing

Thank you for helping improve ExamFlow.

1. Open an issue for material behavior changes.
2. Create a focused branch and keep credentials or runtime data out of Git.
3. Run `./mvnw verify` before opening a pull request.
4. Describe the user-visible change, security impact and manual checks in the pull request.

Use Java 21, constructor injection and the existing Thymeleaf/CSS patterns. Prefer small changes that solve the current problem without adding speculative abstractions.
